# RoomSpell — project documentation

Last updated: 2026-10-14

RoomSpell is a Quest 3/3S mixed reality word game. Three related objects inspire a different word, and players choose scrambled letter tiles to solve it. The Meta camera and neural detector are integrated; challenges use an offline relation bank.
